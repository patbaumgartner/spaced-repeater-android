# Security Policy

## Supported versions

Spaced Repeater is pre-1.0 software. Security fixes are applied to the latest
commit on `main`; older commits and locally modified builds are not supported.

## Report a vulnerability

Please use GitHub's private vulnerability reporting flow:

<https://github.com/patbaumgartner/spaced-repeater-android/security/advisories/new>

Include the affected version or commit, Android version, impact, reproduction
steps, and any proposed mitigation. Do not include private decks, learner data,
or credentials in a report.

## Scope notes

The initial design keeps deck and review data on-device and does not require an
account or cloud service. Reports that identify unintended disclosure or
unauthorized access to local app data are in scope.
